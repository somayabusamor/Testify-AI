# Testify AI 

AI-powered tool for automating unit test generation, designed to improve reliability and reduce manual testing effort.

## Features
- Automatic unit test generation using AI models
- Role-based access control (Admin, Student, Worker)
- Educational modules for students to learn software testing practices

## Tech Stack
- **Backend:** Node.js, Express
- **Frontend:** React
- **Database:** MongoDB
- **AI Tools:** OpenAI API

## Benefits
- Reduces manual testing effort
- Ensures better coverage and reliability
- Provides hands-on learning for software testing
